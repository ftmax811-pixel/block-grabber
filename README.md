# Sigma Block Grabber — Fabric 1.21.1

Tiny prototype for the requested grab/throw mechanic.

### Controls
- Hold a **stick**.
- **Sneak + right-click** a placed block to detach it.
- **Sneak + right-click** again to throw the detached block as a vanilla falling block.

Target: Minecraft 1.21.1, Fabric, Java 21.

This is source code, not a compiled JAR. Build it with Gradle/Fabric Loom (for example via GitHub Actions) and the JAR will appear in `build/libs/`.
